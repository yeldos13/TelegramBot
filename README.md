# AnikiChatBot

Telegram-бот для групповых чатов:

- **Курсы валют** — «100$», «5000 тг», «20 GBP» → сумма в популярных валютах
- **Медиа по ссылкам** — YouTube Shorts и посты, Instagram reels и посты, TikTok видео и фото, X (фото, видео, гифки)
- **Автоответы** — ответ на сообщение запоминается и повторяется, когда кто-то снова пишет тот же текст
- **Игра «Вырасти пенис»** — `/grow` раз в день, `/top`, `/my`, `/name`, `/duel`, `/penisday`, `/achievements` (35 достижений)
- **Итоги недели** в чате по воскресеньям и сообщение, когда кто-то вышел из чата

Тесты: `dotnet test`.

## Игра «Вырасти пенис»

| Команда | Что делает |
|---|---|
| `/grow` | Раз в сутки (сброс в 00:00): первый раз пенис появляется размером 1–20 см, дальше меняется на −20…+20 см (70% — рост, 20% — уменьшение, 10% — без изменений). Меньше 1 см не бывает |
| `/my` | Размер, имя, место в чате, дней подряд, последнее изменение, число достижений |
| `/top` | Топ-50 чата |
| `/name Имя` | Имя пенису (до 64 символов) |
| `/duel` | Вызов на дуэль с кнопкой «Принять»; ответом на сообщение — вызов конкретному человеку. Шанс победы 25–75% в зависимости от размера, победитель забирает 10–25% размера проигравшего, критический удар — 26–40%, нокаут — 50%. Вызов действует 10 минут |
| `/penisday` | Пенис дня — случайный игрок чата, раз в сутки |
| `/achievements` | 35 достижений: размеры (18, 69, 100+, 666, 777…), серии (7/14/30 дней подряд, 3 дня уменьшения…), даты (00:00, 14 февраля, 31 октября…) |

Размер у каждого свой в каждом чате, достижения — общие. Данные хранятся в `penis.json`.

Команды игры и ответы бота удаляются через 15 секунд, кроме `/top` и `/penisday`. Вызов на дуэль висит, пока его не примут (до 10 минут), результат дуэли удаляется через 15 секунд. Чтобы удалялись и команды участников, боту нужно право администратора «Удаление сообщений».
